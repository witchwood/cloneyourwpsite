# Clone your WP site

All-in-One WP Migration **6.77**, modified with a plugin import size limit of **5 GiB**. Free download — качайте, люди добрі 🙂

[Download the plugin ZIP](https://github.com/witchwood/cloneyourwpsite/raw/refs/heads/main/all-in-one-wp-migration-clean.zip)

## Installation

Download the ZIP, then in WordPress open Plugins → Add New → Upload Plugin, select the ZIP and activate it.
